# 维尔萨恩与现代都市高密度扩充设计规格

日期：2026-07-30

状态：设计已确认，等待用户书面规格复核

## 1. 目标

本轮只扩充 DNF 卡中的维尔萨恩与现代都市，不扩充创世回廊、刀剑神域和大明志异。

扩充解决四个问题：

1. 普通与神话种族缺少可结算的特性、属性修正和 RP 价格。
2. 两张新地图节点少、连接关系不可见、缺少旅行与封锁信息。
3. 开局等级虽然部分可选，但缺少对应技能、装备、资源和身份差异。
4. 两个世界各只有 3 名开局队友，角色信息和关系网不足。

采用分层高密度路线。目标为约 130–150 个新增或重写交付单元。

## 2. 不变边界

- 维尔萨恩仍为六国格局，不新增第七个同级国家。
- 玩家不会被默认设为勇者；高等级也不会自动成为勇者或魔王。
- 现代都市的角色等级、异能等级、物种和社会身份相互独立。
- 现代神话种不能觉醒异能。
- 种族不得决定性格、职业、国家、阶层、阵营或善恶。
- 两个世界的地点、角色、势力、状态和剧情不得互相串载。
- 现有三个旧世界的行为与测试不得回归。
- 本轮角色范围为开局可选队友与羁绊角色，不扩充可直接扮演的预设主角。

## 4. 种族机制

### 4.1 RP 价格

| 类型 | RP |
|---|---:|
| 普通种族 | 10 |
| 混血种 | 10 |
| 神话种族 | 20 |

神话种族是普通种族的纯上位选择，不要求用额外负面效果抵消强度。既有能力条件和世界边界仍然保留。

### 4.2 普通种族数值框架

每个普通种族必须包含：

- 2–3 项基础属性修正，单项范围为 `-1～+2`，总正值不超过 `+3`。
- 2 项固定生理特性。
- 1 项从具体动物原型中选择的可选特性。
- 1–2 项环境、装备、体型、感官或行动限制。
- RP、摘要、完整效果和 MVU 永久状态写入文本。

### 4.3 十八个普通种族

| ID | 种族 |
|---|---|
| G-S01 | 犬科 |
| G-S02 | 猫科 |
| G-S03 | 熊科 |
| G-S04 | 鼬科 |
| G-S05 | 小型啮齿与兔形类 |
| G-S06 | 马科 |
| G-S07 | 鹿科 |
| G-S08 | 牛羊羚类 |
| G-S09 | 混血种 |
| G-S10 | 猛禽类 |
| G-S11 | 鸣禽、鸦、鹦类 |
| G-S12 | 水禽与海鸟类 |
| G-S13 | 蜥蜴与蛇类 |
| G-S14 | 龟鳖类 |
| G-S15 | 鳄类 |
| G-S16 | 鲸豚类 |
| G-S17 | 软骨鱼类 |
| G-S18 | 硬骨鱼类 |

G-S09 替换原猪科。其余 17 类暂不替换。

### 4.4 混血种

混血种是不同种族通婚后父系特征显著表达的广义类别。母系仍决定基础体态和主要生殖参数，父系可显现外貌、生理、感官或局部能力。

```yaml
种族分类: G-S09
母系基础分类: G-S01..G-S08、G-S10..G-S18 或 G-M01..G-M08
父系显性来源: G-S01..G-S08、G-S10..G-S18 或 G-M01..G-M08
显性结构:
  外貌特征: []
  生理特征: []
  正面变异: []
  负面冲突: []
```

混血种必须具有两项强正面和两项强负面。正面可以达到属性 `+3～+4`、场景检定 `+4～+5`或显著环境能力；负面必须达到属性 `-2～-3`、对应检定劣势、环境依赖或伤害易损。正面总预算不得高于负面总预算。

神话父系只能显现局部特征或弱化能力，不能直接授予完整神话身份。

## 5. 地图与拓扑

### 5.1 节点字段

每个节点必须包含：

```text
节点ID、所属世界、地图层级、节点类型、所属区域、坐标、
推荐等级、是否可作为出生点、公开描述、当前风险、设施、
势力、角色、支线、相邻节点、连接方式、旅行时间、
通行条件、状态字段
```

每条连接必须包含：

```text
from、to、是否双向、交通类型、距离、基础时间、基础费用、
推荐等级、危险、通行条件、封锁状态字段、替代路线
```

### 5.2 地图界面

地图使用原生 SVG 分层显示，提供：

- 缩放、拖动、图例和节点类型筛选。
- 节点与连接线同步显示。
- 推荐等级和交通类型着色。
- 当前所在地、可达节点和选定路线高亮。
- 节点详情、连接详情和相邻节点列表。
- 最短时间、最低费用和最低风险三种路径。
- 战争、灾害或任务造成的线路封锁显示。
- 隐藏节点解锁前不显示名称和详情。
- 开局只能选择标记为 `spawnable` 的节点。

### 5.3 维尔萨恩地图

目标为 64 个节点、100–115 条连接边：

| 类型 | 数量 |
|---|---:|
| 六国首都 | 6 |
| 地区城市与大型港口 | 12 |
| 村镇、关隘与驿站 | 12 |
| 野外、资源区与特殊地貌 | 12 |
| 遗迹、副本与危险区 | 10 |
| 跨国交通枢纽 | 6 |
| 圣地、魔王相关隐藏节点 | 6 |

每个国家必须有内部环路和至少两条对外路线。海盟有独立海路；山国有隧道、山道和迁跃锚点；城邦联盟承担多路线中转。至少 4 条连接受状态控制。圣地和魔王节点不得在开局泄露。

### 5.4 现代都市地图

目标为 48 个节点、75–90 条连接边，分成两层：

- 全球层：16 个核心城市，以航空、铁路、海运和机构专线连接。
- 城市层：每个核心城市配置 2 个关键城区或异常地点。

全球至少覆盖 7 个区域，每个区域至少两个核心节点。每座城市至少一个日常节点和一个异常节点。至少提供 3 组跨洲替代路线。裂隙事件可以临时增加或切断连接，主线不得强制固定城市。

## 6. 开局等级

两个世界均允许自由选择 `Lv.1–60`，并提供九个快捷档位：

```text
Lv.1 / 5 / 10 / 15 / 20 / 30 / 45 / 50 / 60
```

| 等级 | 定位 | 主要解锁 |
|---:|---|---|
| 1 | 普通新人 | 基础技能、普通装备、额外 20 RP |
| 5 | 受训新人 | 完整基础技能组、基础职业装备 |
| 10 | 正式从业者 | 属性点、职业资格、精良装备 |
| 15 | 转职阶段 | 转职技能、正式机构身份或独立履历 |
| 20 | 资深成员 | 两次攻击、地区级声望、稀有装备资格 |
| 30 | 进阶强者 | 进阶技能、跨地区权限、个人资源 |
| 45 | 顶尖精英 | 必杀技能、国家级或国际级任务入口 |
| 50 | 觉醒者 | 觉醒一、传说装备资格、高风险出生点 |
| 60 | 世界级强者 | 完整一觉成长资源、世界级事件入口 |

每个等级包必须写入等级、累计经验、SP、属性点、攻击次数、技能阶位、建议技能数量、装备品质、资金、身份提示、任务等级、出生点等级和队友同步结果。

维尔萨恩高等级不自动授予政治权力、贵族身份、勇者或魔王身份。现代都市的等级、异能等级和社会身份继续分离。

## 7. 开局队友

每个世界提供 12 名固定候选，共 24 名。开局最多选择 1 名，同时保留“不带队友”和“自定义队友”。

当前 6 名候选的姓名与既有定位可作为角色设计输入，但其现有种族全部撤销。所有 24 名角色先设计定位、关系、职业或异能、技能、装备和个人线，用户确认后才能生成种族。

每名角色至少包含：

```text
角色ID、姓名、年龄、所属世界、出生地、所属势力、职业或异能、
原始等级、六项属性、主动技能、被动特性、装备、个人目标、
当前矛盾、关系网络、入队方式、拒绝条件、三阶段个人线、
成长方向
```

种族确认后再补：

```text
具体种族、种族特性、生理档案、可遗传特征、混血组成
```

角色界面分为档案、战斗、关系和个人线四页，支持按战斗定位、地区、势力和能力类型筛选。角色卡显示原始等级与同步后的开局等级。

## 8. 角色人工门槛

角色生产顺序固定为：

```text
角色定位与世界关系
→ 职业或异能、技能、装备、关系和个人线
→ 人工门槛 A：用户确认
→ 生成每名角色的种族候选和适配理由
→ 人工门槛 B：用户确认最终种族表
→ 写入种族特性、生理档案和混血字段
```

人工门槛 A 前不得出现确定种族。职业或异能技能不得依赖未确定的种族能力。人工门槛 B 前不得写入生理档案。

## 11. 自动化验收

- 26 个种族均有 RP、属性、固定特性和 MVU 状态效果。
- G-S09 同时具有母系基础、父系显性、强正面和强负面。
- 普通及混血 RP 为 10，神话 RP 为 20。
- 维尔萨恩恰有 64 个节点并满足连接门槛。
- 现代都市恰有 48 个节点并保证两层图连通。
- 不存在孤立节点、未知边、重复 ID 或未声明的单向边。
- 三种路径算法返回可解释结果，封锁边不会进入可达路径。
- 两个世界均可选择 `Lv.1–60`。
- 九个快捷等级包的经验、SP、属性点和技能阶位正确。
- 每个世界恰有 12 名开局队友。
- 门槛 A 前角色文件不得出现确定种族。
- 门槛 B 后每名角色才允许生成生理档案。
- 角色、地图、世界书和 MVU 的 ID 逐项一致。
- 两个世界无专属内容串载。
- 三个旧世界的现有测试无回归。
- 汇总 JSON 和单条 JSON 逐字段往返一致。

## 12. 停止规则

出现以下任一情况立即停止当前阶段：

- 用户尚未确认角色定位，却开始确定种族。
- 角色技能依赖尚未确定的种族能力。
- 地图边只有单向声明但未显式标记为单向。
- 新内容改变六国数量、勇者规则或现代异能独立原则。
- 修改覆盖当前 DNF 未提交内容。
- 自动化通过但实际 SillyTavern 尚未验证，却准备报告“实机完成”。
