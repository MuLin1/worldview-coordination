# DNF 五世界模块重做设计规格

状态：设计已确认，尚未开始实现  
日期：2026-07-30  
目标仓库：`dnf`  
当前生效版本：`dist/V20260728`

## 1. 目标

在保留 DNF 现有运行框架和世界切换能力的前提下，完成以下改造：

1. 五个世界全部启用。
2. 保留创世回廊、刀剑神域和大明志异三个模块。
3. 将琥珀之剑模块完整替换为维尔萨恩模块。
4. 将龙族/惊悚乐园模块完整替换为现代都市模块。
5. 接入新世界书的世界观、种族、角色、地图和状态机规则。
6. 为玩家及所有成年羁绊角色增加统一的自然周期、受孕、妊娠、生育和后代结算。
7. 对两个被替换模块的旧种族、旧角色和旧数值进行整体重制，而不是只替换显示名称。

本次不要求兼容原琥珀之剑、龙族或惊悚乐园存档。

## 2. 世界模块范围

| 当前模块ID | 当前世界 | 改造结果 | 处理方式 |
|---|---|---|---|
| `corridor` | 创世回廊 | 保留并启用 | 不做世界观改编，仅接入通用生殖配置 |
| `sao` | 刀剑神域 | 保留并启用 | 不做世界观改编，仅接入通用生殖配置 |
| `jiuzhou` | 大明志异 | 保留并启用 | 不做世界观改编，仅接入通用生殖配置 |
| `amber` | 琥珀之剑 | 维尔萨恩 | 世界观、地图、角色、种族和状态全部替换 |
| `dragon` | 龙族/惊悚乐园 | 现代都市 | 世界观、地图、角色、种族和状态全部替换 |

新模块正式标识采用：

```text
vielsaen -> 维尔萨恩
modern    -> 现代都市
```

旧 `amber`、`dragon` 标识不作为兼容别名保留。所有有效调用点直接迁移到新标识。

## 3. 总体设计

采用“配置层 + 状态引擎”结构，保留现有页面、状态栏和移动端框架。

```text
现有 DNF UI
├─ 世界选择与切换
├─ 外部状态栏
├─ 移动端羁绊页
├─ 开局与角色预设
└─ 地图入口
        │
        ▼
统一配置层
├─ 五世界注册表
├─ 18类普通生物配置
├─ 8类神话生物配置
├─ 角色与羁绊模板
├─ 周期与妊娠参数
└─ 地图节点与事件配置
        │
        ▼
状态引擎
├─ 世界模块隔离
├─ 时间与自然周期
├─ 受孕、妊娠与生育
├─ 维尔萨恩专属状态
└─ 现代都市专属状态
```

设计原则：

- 不重写能够继续使用的 UI 框架。
- 世界差异放入配置和专属状态，不在多个页面重复硬编码。
- 计算结果由脚本产生，AI 只提交事件和负责叙述。
- 五个世界使用相同的年月日结构。
- 世界切换后只加载当前世界的专属规则，不并行混用。
- 跨世界内容只允许作为低频彩蛋，不改变任何世界的主要矛盾。

## 4. 世界切换与模块隔离

世界选择器显示五个世界，保留原版本可切换世界的能力。

切换过程：

```text
用户选择世界
  -> 校验世界ID
  -> 保存当前世界
  -> 卸载上一世界的专属显示和事件
  -> 加载目标世界的配置、地图与状态
  -> 共享状态继续可用
```

隔离规则：

- 共享生殖系统可以在五个世界运行。
- 维尔萨恩状态只在 `vielsaen` 中推进。
- 现代都市状态只在 `modern` 中推进。
- 创世回廊、刀剑神域和大明志异不得误读 V/U 专属状态。
- 旧琥珀之剑、龙族和惊悚乐园提示词不得再被新模块加载。
- 切换世界不能自动删除其他世界已保存的独立状态。

## 5. 变量结构与权威边界

### 5.1 角色生理档案

玩家和每个羁绊角色拥有独立的 `生理档案`：

```yaml
生理档案:
  是否成年: true | false
  生理性别: 雌性 | 雄性 | 双性 | 无性 | 可变
  生殖能力: 可妊娠 | 可授精 | 双向 | 无
  生物体系: 普通 | 神话
  生物大类: 配置ID
  具体种族: 文本或注册ID
  可遗传特征: []

  自然周期:
    是否启用: true | false
    配置ID: ""
    周期起始日期: ""
    当前阶段: ""
    周期序号: 0
    抑制状态: 无 | 抑制 | 调节
    个体偏移天数: 0

  妊娠:
    状态: 未妊娠 | 妊娠中 | 待分娩 | 已结算
    受孕事件ID: ""
    授精方ID: ""
    开始日期: ""
    预计分娩日期: ""
    剩余天数: 0
    生育方式: 胎生 | 卵生
    预计数量: 0
    待结算: false

  后代记录: []
```

`是否成年` 为显式字段，不通过统一数值年龄线临时推断。建立或更新角色档案时，应结合角色日期、种族和个体设定确定该字段。

### 5.2 生殖系统根状态

```yaml
生殖系统:
  请求账本: []
  结算账本: []
  待生育事件: []
  生育记录: []
```

每个事件必须具有唯一事件ID。脚本通过事件ID保证重复响应、重新渲染或页面刷新不会重复进行受孕或生育结算。

每次结算保存当时使用的参数快照，避免配置更新后改写历史结果。

### 5.3 世界状态

```yaml
世界状态:
  当前世界: corridor | sao | jiuzhou | vielsaen | modern
  维尔萨恩: {}
  现代都市: {}
  跨世界彩蛋: {}
```

与个体绑定的魔力数据和异能数据放入角色档案：

```yaml
魔力档案: {}
异能档案: {}
```

不得把所有角色的魔力或异能压入一个不可追踪的全局数值。

### 5.4 写入权威

| 数据 | AI权限 | 脚本权限 | 手动修正 |
|---|---|---|---|
| 人物种族与生理档案建议 | 可提出 | 校验并写入 | 允许 |
| 亲密事件结构化请求 | 可提交 | 校验并登记 | 允许撤销错误请求 |
| 是否受孕 | 不可决定 | D100检定并写入 | 允许 |
| 周期阶段与剩余天数 | 不可决定 | 按日期计算 | 允许修正源数据 |
| 妊娠推进与分娩时间 | 不可决定 | 按日期计算 | 允许 |
| 后代性别与特征 | 不可决定 | 随机结算 | 允许 |
| 剧情、感受和场景叙述 | 负责 | 不负责 | 不适用 |

AI 不得用自然语言直接覆盖脚本结算结果。

## 6. 时间系统

五个世界统一使用：

```text
世界前缀 + 年 + 月 + 日
```

周期和妊娠按现实尺度的天数/月数运行，不使用回合数或模糊剧情阶段代替。

时间解析流程：

```text
读取日期
  -> 识别世界前缀
  -> 解析年月日
  -> 与角色上次结算日期比较
  -> 推进周期、妊娠和世界状态
```

不新增对用户可见的绝对日计数器。内部可以用标准日期差计算天数，但不得改变五世界统一的显示格式。

日期无效、倒退或无法解析时停止推进并显示错误，不猜测时间。

## 7. 自然周期系统

适用对象：

- 玩家。
- 所有 `是否成年 = true` 的羁绊角色。
- 具有有效周期配置且未永久关闭周期的角色。

周期只产生生理状态和叙事提示：

- 不直接修改战斗属性。
- 不强迫角色采取行动。
- 不替代角色意愿或同意。
- 可以通过医疗、药物或个体设定进行抑制和调节。

### 7.1 普通生物

普通生物按世界书的18个生物大类统一配置：

1. 犬科。
2. 猫科。
3. 熊科。
4. 鼬科。
5. 小型啮齿与兔形类。
6. 马科。
7. 鹿科。
8. 牛、羊与羚类。
9. 猪科。
10. 猛禽类。
11. 鸣禽、鸦与鹦鹉类。
12. 水禽与海鸟类。
13. 蜥蜴与蛇类。
14. 龟鳖类。
15. 鳄类。
16. 鲸豚类。
17. 软骨鱼类。
18. 硬骨鱼类。

每类配置至少包含：

```yaml
周期长度范围: ""
活跃阶段范围: ""
季节性: ""
默认个体偏移: ""
妊娠或孵化时长范围: ""
生育方式: 胎生 | 卵生
单次后代数量范围: ""
可调节方式: []
```

具体种族可以在大类配置上做有限修正，但不能另建一套重复引擎。

创世回廊、刀剑神域和大明志异原种族不自动映射到18类。实施时为这些世界增加独立的“生殖分类”字段，由角色配置明确指定。

### 7.2 神话生物

神话生物具有自然周期，但使用独立的神话生物周期配置，不归并到18类普通生物配置。

首期支持八类：

1. 巨龙。
2. 凤凰。
3. 麒麟。
4. 狮鹫。
5. 深海巨兽。
6. 独角兽。
7. 雷鸟。
8. 多首巨蛇。

神话配置同样负责周期、妊娠或孵化时长、生育方式和后代数量。

## 8. 受孕、妊娠与生育

### 8.1 受孕请求

AI 在发生符合条件的事件后提交结构化请求：

```yaml
事件ID: ""
日期: ""
参与者ID: []
妊娠候选ID: ""
授精候选ID: ""
是否体内授精: true | false
避孕措施: []
健康与年龄证据: {}
世界修正证据: {}
```

脚本先验证：

- 参与者均已成年。
- 生殖能力组合有效。
- 事件数据完整。
- 事件ID未结算。
- 妊娠候选当前未处于不可再次受孕状态。

不满足条件时记录拒绝原因，不进行随机检定。

### 8.2 D100受孕检定

检定由脚本完成：

```text
基础概率
  + 当前周期阶段修正
  + 生殖能力修正
  + 健康与年龄信息修正
  + 避孕措施修正
  + 当前世界明确配置的修正
  = 最终受孕概率

D100 <= 最终概率 -> 受孕成功
D100 >  最终概率 -> 未受孕
```

维尔萨恩的魔力枯竭发情与自然周期是两个独立状态，可以同时发生，但魔力枯竭状态不提高受孕概率。

### 8.3 妊娠推进

受孕成功后：

1. 写入妊娠开始日期。
2. 根据妊娠方的普通或神话配置确定妊娠/孵化时长。
3. 根据妊娠方配置确定胎生或卵生。
4. 根据妊娠方配置确定胎数或蛋数范围并进行结算。
5. 计算预计分娩日期和剩余天数。
6. 在状态栏和羁绊详情中持续显示。

妊娠方决定基础种族、基础身体结构和生育方式。

### 8.4 生育结算

达到预计日期后进入待生育状态，脚本对每个后代分别结算：

```yaml
后代ID: ""
出生日期: ""
妊娠方ID: ""
授精方ID: ""
基础种族: ""
生物体系: 普通 | 神话
生理性别: ""
遗传特征: []
出生方式: 胎生 | 卵生
个体备注: {}
```

性别概率：

```text
雄性：49%
雌性：49%
双性、无性或可变：合计2%
```

特征结算规则：

- 基础种族和基础身体结构由妊娠方决定。
- 从双方已登记的 `可遗传特征` 中抽取表现。
- 父系或非妊娠方特征不自动改变基础种族。
- 具体毛色、鳞色、羽色、纹路、角、耳、尾、翼、感官和少量亲和可以遗传。
- 不能凭空继承未登记的完整神话能力、社会身份或职业。

纯血与混血由脚本根据双方基础物种判定：

```text
双方基础物种相同 -> 纯血
双方基础物种不同 -> 混血
```

混血后代仍以妊娠方为基础物种，另一方只参与已登记特征的表达。现代都市中的纯血或混血不得直接提高异能等级或觉醒概率；维尔萨恩如存在魔法表现差异，只能读取维尔萨恩专属配置。

脚本保存结构化结果，AI 根据结果叙述出生过程和个体表现。

## 9. 维尔萨恩模块重做

旧琥珀之剑内容完整移除并替换为维尔萨恩：

- 艾沃兰大陆与瑟雷亚海。
- 六个国家及其地理、势力和关系。
- 六大魔法学派。
- 七神信仰体系。
- 神话生物在维尔萨恩的专属身份。
- 魔王、勇者、圣地和五个月空窗期相关状态。
- 维尔萨恩专属成人与魔力规则。

需要实现的状态接口包括：

```text
魔王是否公开
勇者是否出现
勇者候选与确认状态
圣地状态
五个月空窗期进度
魔力枯竭状态
剧情证据与阶段推进
```

玩家不得默认成为勇者；魔王在开局阶段不得被公共社会直接确认。

旧琥珀之剑国家、组织、职业、种族、人物、装备、技能、事件和提示词不得作为新模块内容残留。

## 10. 现代都市模块重做

旧龙族/惊悚乐园内容完整移除并替换为现代都市：

- 2026年平行地球。
- 全球主要城市节点图。
- 公开异能社会。
- 八类异能生成和登记。
- 隐藏神话生物。
- 裂隙、异界魔物和魔物王入侵。
- 0—7阶段现代都市主线。
- 成人内容触发保护。

需要实现的状态接口包括：

```text
角色异能生成
异能类别与等级登记
觉醒证据
主线0—7阶段
裂隙状态
异界魔物活动
魔物王入侵状态
成人触发保护
```

现代都市规则：

- 异能与种族分离。
- 普通种族不能固定绑定某类异能。
- 神话生物不能觉醒异能。
- 主线只能在具备对应剧情证据时推进。
- 旧锁情咒、龙族副本、惊悚乐园副本和副本评价字段全部替换。

## 11. 种族系统迁移

两个被替换模块不能只修改种族名称，必须同步替换：

- 种族名称和种族ID。
- 所属普通18类或神话8类。
- 生殖能力和自然周期配置。
- 妊娠时长、胎生/卵生和后代数量。
- 外貌、生理、寿命和遗传特征。
- 种族天赋、抗性和属性倾向。
- 与职业、魔法或异能有关的合法修正。
- 状态栏、羁绊页、开局预设、提示词和地图事件中的描述。

维尔萨恩不得继续使用旧琥珀之剑种族体系。

现代都市不得把异能名称写入种族字段，也不得把异能类型与具体种族绑定。

数值允许根据新种族描述重新调整，以保证文本设定与实际表现一致。

两个新模块同时遵守世界书种族硬约束：

- 本地文明主体全部为 furry。
- 不存在本地人类。
- 不使用精灵、哥布林、矮人等类人种族。
- 排除猴、猿及其他灵长类 furry。
- 普通种族必须归入18个普通生物大类之一。
- 神话种族必须归入独立的八类神话生物配置之一。
- 种族不得固定绑定国家、职业、阶层、善恶、魔法学派或异能类别。

## 12. 羁绊角色整体替换

原琥珀之剑、龙族和惊悚乐园专属羁绊角色全部删除并替换为新世界原创角色。

不保留：

- 原姓名和角色ID。
- 原作品身份。
- 原背景与人物关系。
- 原种族。
- 原职业、装备和技能。
- 原等级和属性数值。
- 原开局事件和羁绊文本。

原创替代角色必须完整配置：

```text
姓名与新角色ID
世界归属
具体种族及生物大类
成年状态与生殖能力
外貌和身体特征
可遗传特征
性格与关系定位
出生地、阵营与经历
职业、魔法或异能
装备与技能
等级、属性和战斗数值
羁绊初始值和触发事件
状态栏与移动端描述
```

新角色可以承担旧角色必要的玩法职责，例如前卫、治疗、支援或情报，但不得沿用旧角色身份和设定。

### 12.1 归属审计

实施前对所有硬编码角色建立归属表：

| 角色归属 | 处理 |
|---|---|
| 创世回廊专属 | 保留 |
| 刀剑神域专属 | 保留 |
| 大明志异专属 | 保留 |
| 琥珀之剑专属 | 删除并创建维尔萨恩原创替代 |
| 龙族/惊悚乐园专属 | 删除并创建现代都市原创替代 |
| 公共或归属不明 | 根据实际调用路径确定，不按名称猜测 |

同一角色可能同时硬编码在计算器、构建页和状态栏中。必须按角色ID和调用路径完整迁移，不能只改其中一个副本。

## 13. 角色数值重算

两个新模块的角色数值不继承旧等级。

重算顺序：

```text
角色玩法职责
  -> 新世界实力层级
  -> 种族基础特征
  -> 职业、魔法或异能
  -> 装备与技能修正
  -> 最终等级与属性
```

数值要求：

- 描述为普通成年人的角色不得保留旧版高等级属性。

## 18. 验收条件

### 18.1 世界模块

- 五个世界均可选择和切换。
- 任一时刻只加载当前世界专属内容。
- 三个保留世界仍可正常运行。
- 维尔萨恩有效路径中没有琥珀之剑专属内容。
- 现代都市有效路径中没有龙族或惊悚乐园专属内容。

### 18.2 种族与角色

- 两个新模块的种族均能映射到18类普通生物或8类神话生物。
- 旧模块专属羁绊角色已完整替换为原创角色。
- 角色描述、种族特征、技能和数值一致。
- 保留世界的角色未被误删或误改。
- 公共角色的世界归属有可追踪证据。

### 18.3 生殖系统

- 玩家及所有成年羁绊角色可独立推进自然周期。
- 普通生物和神话生物使用不同配置。
- 重复事件ID不会重复受孕或重复生育。
- 受孕必须经过脚本D100检定。
- 妊娠状态能显示预计日期和剩余时间。
- 生育后能生成数量、性别、基础种族和遗传特征。
- 时间无效时不会静默推进。
- AI不能直接覆盖脚本结算。

### 18.4 世界专属状态

- 魔力枯竭与自然周期可重叠，但不会提高受孕率。
- 维尔萨恩勇者、魔王、圣地和空窗期按证据推进。
- 现代都市异能与种族分离。
- 神话生物不会觉醒异能。
- 现代都市0—7主线没有证据时不能越级。

### 18.5 静态清理

对所有当前可调用文件执行旧名称扫描：

- 允许旧名称存在于明确的历史说明或迁移清单。
- 不允许旧名称存在于两个新模块的运行配置、提示词、角色模板、地图数据和状态显示中。

## 19. 当前不做

- 不为原琥珀之剑、龙族或惊悚乐园存档建立兼容层。
- 不对创世回廊、刀剑神域和大明志异进行世界观重写。
- 不为三个保留世界增加专属生殖剧情，只接入通用配置和引擎。
- 不让自然周期直接改变战斗数值或强制角色行为。
- 不让AI取代脚本进行受孕、妊娠或后代随机结算。
